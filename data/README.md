# Dataset setup

Download the original CSV from https://www.kaggle.com/datasets/jr2ngb/superstore-data (sign in to Kaggle if prompted). Place the downloaded transaction CSV here and name it exactly `superstore.csv`. The application does not create substitute or random data.

Before publishing this file in a public GitHub repository, check the dataset's current Kaggle license and redistribution terms. If redistribution is not permitted, keep the CSV out of public Git and use a permitted private/source-hosted data strategy; note that Vercel will then need access to the data at runtime.
